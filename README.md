# AI Group UI

用于在前端管理 AI 分组、分组用户绑定，以及供应商、模型、MCP、专家、知识库和技能的可见范围

## 插件类型

- 前端插件

## 配置说明

无需额外环境变量或前端运行时配置

安装前请确保后端 AI Group 插件已启用，并已完成对应菜单和权限配置

## 使用方式

1. 安装并启用后端 AI Group 插件和前端 AI Group 插件
2. 在菜单中进入 AI 分组管理页面
3. 创建分组并维护分组基础信息
4. 在列表操作列中配置分组用户和 AI 资源可见范围

## 卸载说明

- 卸载插件后，建议同步移除 AI 分组相关菜单和权限
- 如业务流程已依赖 AI 分组能力，请同步清理对应集成
